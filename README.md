# Loja Turma Tarde - Sistema para Testes QA

Sistema desenvolvido com **erros intencionais** para testes de Quality Assurance.

## Problemas conhecidos (para testar):

- Login aceita qualquer senha com usuário "admin"
- Dados não atualizam após edição
- Carregamento lento (setTimeout)
- Validações ausentes
- Rotas protegidas inconsistentes
- UI quebra em telas pequenas
- Dados duplicados e inconsistentes

## Instalação

```bash
npm install
npm run dev
```
